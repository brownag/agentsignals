## Notes
- Tool errors scanned over assistant messages only (content only exists there); part rows grouped by message_id.
- is_git_discernable only recognises tool names "Edit"/"Write" (capitalised); opencode uses lowercase "edit"/"write"/"shell", so only the `git status/diff/log` empty-output branch applies. I will call it unchanged (miner.py is out of scope).
- Case (b) with no `metadata.exit` but signal/timeout truthy: exit_code=None, no "Exit code" suffix.
- Case (c) fires only when status=="completed", no metadata.exit key, and text has non-zero code; exit_code parsed from first non-zero match.
- Timestamp from ms epoch; `time.completed` falsy -> fall back to created.
